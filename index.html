Corrected model: earlier versions forced all 6 locations to be the same joint type — which can only ever land on "trivially exact with 1 rigid joint," degenerate, or overconstrained. Real kinematic mounts (a Kelvin clamp, a machine-shop 3-2-1 fixture) get to exactly 6 constraints by mixing different contact types and orientations: e.g. 3 flat contacts (1 DOF each, defining a plane) + 1 V-groove (2 DOF, defining a line) + 1 point (1 DOF, killing the last rotation) = 3+2+1 = 6, exactly. Hit the "Classic 3-2-1 (exact)" preset to see a real, non-trivial 6-DOF-exact solution, then edit any joint's type/orientation yourself and watch the classification update live. Once you've got something exact or overconstrained, use the tolerance + compliance controls to see where self-stress shows up and how local flexibility relieves it.

Model: 6 joint slots evenly spaced on a rover ring, each directly above a matching lander point, each independently configurable. Pin reacts 1 translation axis (flat/point contact). Shear pin reacts the 2 axes NOT chosen (V-groove/dowel, free along its own axis). Ball reacts all 3 translations, no moment. Clevis reacts all 3 translations plus 2 of 3 moments (free to rotate about the chosen hinge axis). Rigid reacts all 6. Global stiffness K = Σ kᵢ·rowᵢ⊗rowᵢ, each row a screw-theory constraint [â, r̂×â] (or [0, n̂] for a pure moment), solved directly (Gaussian elimination, no canned answers) for an applied lunar-gravity wrench and for an imposed length-error vector at the selected joint/axis.
